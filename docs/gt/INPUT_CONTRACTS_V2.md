# 输入契约 v2（2026-10-12 定稿方向）

学长结论：**输入必须包含 intent**，否则"该讲什么"无法判定，评测就退化成看图说话。
原来的 B1（只给 table）与 B5（只给图）作废，改用下面四档。

## 0. 输入的统一组成（2026-10-12 追加）

四档输入都包含 **chart_spec**（图型，细到小类型）。学长口径：不指定图型的话，
不同模型用不同画法（堆叠柱 vs 分组柱）实现同一个 clip，分数就没有可比性。
受控词表与逐条 spec 见 `CHART_SPEC.md` 与 `data/generated/chart_spec/`。

因此每档输入的完整清单是：

| 组成 | V1 | V2 | V3 | V4 |
|---|---|---|---|---|
| intent | ✓ | ✓ | ✓ | ✓ |
| data table | ✓ | ✓ | ✓ | ✓ |
| chart_spec | ✓ | ✓ | ✓ | ✓ |
| narration 文本 | | ✓ | | ✓ |
| reference svg | | | ✓ | ✓ |

## 1. 四档契约

| 代号 | 输入 | 模型负责 | 与旧编号的关系 |
|---|---|---|---|
| **V1** | intent + table + chart_spec | 旁白、布局、动画 | = 旧 B2（现有 340 条草稿就是这一档） |
| **V2** | intent + narration + table + chart_spec | 布局、动画（旁白已给） | = 旧 B3 |
| **V3** | intent + table + chart_spec + svg | 旁白、动画（图形与风格已给） | 新增 |
| **V4** | intent + narration + svg + table + chart_spec | 只做动画与时间同步 | ≈ 旧 B4 |

排序按"给定越多、自由越少"：V1 最难，V4 最接近"把一张静态图动画化"。
四档不可混榜，V3/V4 因为拿到 SVG，分数天然更高。

自 2026-10-12 起，**图型由 chart_spec 给定，不再是模型的选择**；
画错图型记一条"违反给定约束"，而不是扣语义完成度。

## 2. 各档的 GT 差异

### G0 数据事实基础

| 档 | 答案键来自哪里 | 特别约定 |
|---|---|---|
| V1 / V2 | 只来自 `data_table.csv` 与 intent | 图里印了什么不影响评分，模型没拿到图 |
| V3 / V4 | 表仍是事实基准，但 SVG 里的印刷值同时出现在输入里 | 每个事实要标 `given_in_input`。已 given 的事实不参与"抽取能力"计分，只用来验证模型有没有抄错 |

### G1 必需语义单元

| 档 | 单元怎么定 | 数量 |
|---|---|---|
| V1 | 按协议 §2.4 从 intent 拆槽、从 table 填单元（C1–C4 四条判定） | 由槽数决定，实测 1–4，均值 1.76 |
| V2 | 单元 = **给定旁白里明确断言的量化事实**（任务就是把这段旁白画出来），再用表核对断言是否成立 | 由旁白断言数决定，1–5 |
| V3 | V1 的语义单元 **+ 风格义务**：图型、系列身份、图例名、关键标签、配色家族 | 语义由槽数决定 + 风格 2–3 |
| V4 | V2 的旁白断言 **+ 风格义务**；数据抽取不再是考点，重心移到动画与时序 | 同上 |

**单元的定义与判定统一走协议 §2.4**（P/B/E 三元组 + C1 可判定 / C2 非平凡 / C3 删除测试 / C4 独立；C3 不过降为 optional_valid）。条数是数出来的，不是配额：旧版按"3–5 条"写出的 50 条抽样有 27% 是共用同一组数据点的重复，按 §2.4 重跑后为 88 条、0 重复。

**bar 完整性 requirement：** 每条 bar clip 的第一个 requirement 固定为
`R1`，问题为“这个视频是怎么展现这些 bar 的？”。单状态图在 R1 下一个 U
列出全部数据柱和堆叠段；状态序列图每个状态各一个 U，R1 用 `all_of` 绑定。
每个完整性 U 都和其他语义 U 一起按等权进入 G1，G2 负责检查对应图元是否存在。

新增一个单元类型，四档都要有：

**`narrative_claim`（叙事义务）**：至少一个"不是复述数字"的洞见单元，
例如比较、趋势、异常、结论。判据是这句话是否在做**解释或判断**，而不是把表里的数念一遍。
这是当前 baseline 最弱的一环（见第 4 节）。

风格义务只在 V3/V4 进完成度；在 V1/V2 因为没给参考图，"像不像原图"只能进人评。

### G2 视觉证据规范

四档共用同一套规则：每个单元都要写"要看到什么图元、标注或比例才算真的画出来"。
V3/V4 追加一条：**与参考图同构**（同样的图型、同样的系列数、同样的标签）也算充分证据。

### G3 时间关系规范

| 档 | 锚点 |
|---|---|
| V1 / V3 | 锚在**模型自己写的**旁白句上（我们评它有没有在说话时把证据放出来） |
| V2 / V4 | 锚在**给定的**旁白句上（旁白已固定，容差可以收紧到 1.0–1.5 s） |

### G4 人工验证集

四档各自分层抽样。人工抽样规模定为 **50 条**（见 `g1_review_50.csv`），
按 family 配比并偏向审计里被标记过的 clip。

## 3. 两类容差（不变）

| 容差 | 判什么 | 是否扣模型分 |
|---|---|---|
| `model_tolerance` | 输出的数与我们给的表是否一致，只吸收测量误差 | 扣 |
| `dataset_uncertainty` | 我们的 GT 与原视频是否一致，含估读误差 | 不扣，只进数据质量报告 |

V3/V4 多一条要记录的边界：SVG 里的印刷值来自我们的重建，属于 `dataset_uncertainty`，
模型照着念不算错。

## 4. 当前 baseline 的已知短板

现有 B2 提示词（`baseline_audio.py` 的 `NARR_PROMPT`）写的是：

> Write the narration for a 15-20 second data video as 3-4 short English sentences.
> **Base every number on the table below; do not invent data.**

这句话直接把模型推向"把表念一遍"。DataReel 的裁判标准里，
`Informativeness` 明确把"只是读数据"判为 1 分（0–5 分制）。
所以现在这条 baseline 的字幕既没有信息量，也不好打分：满分与零分之间没有区分度。

修法（三步一起做，缺一不可）：

1. **提示词**要求每句必须给出一个判断：比较、趋势、异常或结论，数字只能作为证据出现；
2. **GT** 增加 `narrative_claim` 单元，把"有没有洞见"变成可判定的义务；
3. **指标**增加"复述率"：字幕句里只包含表中已印刷数字、且没有任何比较或判断词的比例。
   复述率高 = 分低，且这条是自动可算的，不需要人评。
